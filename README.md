# Abdullah Ahmed - Digital Craftsman Portfolio

A sophisticated, dark-themed personal portfolio showcasing the intersection of timeless elegance and modern innovation. Built with Next.js, Tailwind CSS, and shadcn/ui, featuring an exquisite old money aesthetic with refined animations and decorative elements.

## ✨ Enhanced Features

- **Sophisticated Design**: Deep navy theme with eggshell white typography and golden accents
- **Premium Typography**: Cormorant Garamond for elegant display text, Inter for body content
- **Advanced Animations**: Floating elements, gradient flows, and smooth transitions
- **Mobile Navigation**: Responsive hamburger menu with elegant animations
- **Ornamental Details**: Decorative dividers, elegant borders, and sophisticated hover effects
- **Real Experience**: DirectFN Software Engineer Internship with actual technologies
- **Featured Projects**: Formai AI-powered form generator with live demo links
- **Interactive Elements**: Sophisticated card interactions and animated navigation
- **Responsive Excellence**: Flawless experience across all device sizes including mobile
- **Modern Stack**: Built with Next.js 15, Tailwind CSS 4, and TypeScript

## 🎨 Design Philosophy

This portfolio embodies the principles of old money elegance:
- **Understated Luxury**: Refined without being ostentatious
- **Timeless Typography**: Classical serif fonts for sophistication
- **Minimal Color Palette**: Sophisticated dark theme with gold accents
- **Purposeful Elements**: Every component serves a clear function
- **Attention to Detail**: Carefully crafted spacing, typography, and interactions

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ 
- npm or yarn

### Installation

1. Navigate to the project directory:
   ```bash
   cd portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser

## 🛠 Customization

### Content
- Update personal information in `src/app/page.tsx`
- Modify the projects in the "Selected Work" section
- Add your social media links in the contact section

### Styling
- Color scheme: Modify CSS variables in `src/app/globals.css`
- Typography: Adjust font imports and variables in the same file
- Layout: Customize spacing and structure in `src/app/page.tsx`

### Metadata
- Update SEO information in `src/app/layout.tsx`
- Replace placeholder URLs and descriptions
